How it works

Three layers. Each does what it does best.

┌─ Deterministic rule engine ────────┐ waste knowledge base · sorting advisor · tracking └────────────────────────────────────┘ ┌─ Business intelligence layer ────────┐ EPA-grounded cost models · 0–100 scoring · ROI ranking └────────────────────────────────────┘ ┌─ LLM advisor (AMD-hosted) ───────────┐ synthesizes grounded figures into conversational advice └────────────────────────────────────┘

Design principle: the LLM never invents a number. All figures are US national averages, labeled as estimates.

The AMD angle

The intelligence runs on AMD.

  • LLM served with vLLM on ROCm-ready AMD Instinct GPUs via AMD Developer Cloud
  • Config change only — OpenAI-compatible API means zero code changes to move backends
  • Meaningful workload, not a checkbox — every answer is synthesized by the model; it is the product
